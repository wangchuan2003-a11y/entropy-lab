# 模型参考

查阅日期：2026-09-07。通过Jina Reader阅读 [Random Services: The Ehrenfest Chains](https://www.randomservices.org/random/markov/Ehrenfest.html) 的基本模型、修正版、周期性与不变分布相关段落。该公开概率教材用球与双箱描述Ehrenfest链，本文不复制源代码。

来源说明：基本模型每步随机选球并移到另一箱，宏观状态记录一箱球数；基本链有周期2。修正版每步独立随机选球与目标箱，因而可能保持原位，是非周期链。两者的不变分布都是二项分布。

本项目采用等价的lazy实现：选标签粒子，再以公平硬币决定换箱或保持。取左箱计数k，转移为P(k,k−1)=k/(2N)、P(k,k)=1/2、P(k,k+1)=(N−k)/(2N)。二项权重π(k)=C(N,k)/2^N满足π(k)P(k,k+1)=π(k+1)P(k+1,k)，可独立用组合数递推验证详细平衡。

本项目自行实现log-factorial来计算log₂ C(N,k)，在log空间构造理论概率。图中的bits是标签微观状态多重度的对数，不赋予温度、能量或空间解释。粒子坐标是界面布局，不是模型中的位置。

保存事件与伪随机状态使软件可以精确倒退和重放；这依赖额外记录的信息，不能当成自然自发逆转或对热力学第二定律的反例。有限轨迹的直方图只作观察，不证明平稳性、收敛速率或现实系统的规律。相邻样本相关，初始全左也不是平稳抽样。
